# 碎星 · VR 节奏游戏

夜色湖面上的原创 VR 节奏游戏。双手各持一把光刃，按节拍和方向劈碎飞来的星晶。

在线游玩：<https://liyucheng1997.github.io/466_VR-beat-dance/>

用 VR 头显的浏览器打开（Pico、Quest 等支持 WebXR 的浏览器），点「进入 VR」。没有头显也可以在电脑上点「桌面预览」，用鼠标挥砍。

## 玩法

- 左手琥珀光刃，右手青色光刃，劈碎同色的星晶
- 星晶上的箭头是挥砍方向，圆环表示任意方向
- 进入后劈开「普通」或「困难」星晶开始
- 连击越高倍率越高，最高 ×8；结束后给出评级

## 实现

- three.js + WebXR，纯静态网页，无需构建
- 音乐和音效由 WebAudio 实时合成，没有任何音频文件
- 谱面按曲子的段落结构用固定种子生成

## 本地运行

```
node server.js
```

然后打开 <http://localhost:8466>。连着 USB 的头显可以用 `adb reverse tcp:8466 tcp:8466` 后在头显浏览器里访问同一个地址。
